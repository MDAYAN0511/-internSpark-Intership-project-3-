# Instagram Engagement Analysis 

## Project Overview

This project analyzes Instagram engagement data to identify the best posting times, high-performing content types, hashtag effectiveness, and follower growth signals. The analysis aims to provide actionable recommendations that can help Alfido Tech improve its social media engagement and optimize its content strategy.

## Objectives

* Perform Exploratory Data Analysis (EDA) on Instagram dataset.
* Calculate engagement metrics such as likes and comments per follower.
* Analyze posting schedules and identify optimal posting times.
* Evaluate content types and hashtag performance.
* Generate visual insights through charts and graphs.
* Recommend a content calendar and engagement growth strategies.

## Dataset Description

The dataset contains Instagram-related information spread across multiple files:

| File Name      | Description                        |
| -------------- | ---------------------------------- |
| users.csv      | User account information           |
| photos.csv     | Instagram post details             |
| likes.csv      | Likes received on posts            |
| comments.csv   | Comments on posts                  |
| tags.csv       | Hashtag information                |
| photo_tags.csv | Mapping between posts and hashtags |
| follows.csv    | Follower-following relationships   |

## Engagement Metrics

The following metrics were calculated:

* Total Likes per Post
* Total Comments per Post
* Followers per User
* Likes per Follower
* Comments per Follower
* Overall Engagement Rate

Engagement Rate Formula:

Engagement Rate = (Likes + Comments) / Followers

## Key Findings

* Certain posting hours consistently generate higher engagement.
* Some content types outperform others in terms of engagement rate.
* Strategic hashtag usage contributes to improved reach and engagement.
* Consistent posting schedules can positively impact audience interaction.
